# Smart Doorbell with Mobile Notification Using ESP32 and KiwisIoT

## About the Project

The **Smart Doorbell with Mobile Notification** is an IoT-based home automation project designed to notify homeowners whenever a visitor presses the doorbell.

Using an ESP32 microcontroller, the system detects doorbell button presses and sends instant notifications to the user's mobile through the KiwisIoT platform over Wi-Fi. This allows homeowners to know when someone is at their door, even when they are away from home.

By integrating KiwisIoT, this project demonstrates a simple and convenient approach to smart home connectivity and remote visitor notifications.
